# terraform-modules
This repository contains modules for terraform resources, these can be used for the given providers. This repo is more or less a reusable repository, open for all


Steps to Start:

1. Install terraform

2. Install terragrunt

3. Navigate to the directory : terraform-modules/terragrunt/region/environments/dev/

4. Select a module which you want to deploy for e.g namespaces, cd namespaces

5. terragrunt init

6. terragrunt plan

7. terragrunt apply
